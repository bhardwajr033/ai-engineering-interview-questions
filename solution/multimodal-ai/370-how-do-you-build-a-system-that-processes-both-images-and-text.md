# How do you build a system that processes both images and text?

**Topic:** Multimodal AI

## Multimodal AI

Multimodal AI processes and connects multiple data types such as text, images, audio, video, and structured documents.

Key points:
- Vision-language models combine visual encoders with language models to answer questions or generate descriptions.
- CLIP-style models learn aligned text and image embeddings for cross-modal retrieval.
- Diffusion models generate media by denoising latent representations under text or image conditioning.

## Example

Example: a document-understanding system reads scanned invoices by combining OCR, layout analysis, visual embeddings, and language reasoning.

## Current Software Engineering Use Case

Multimodal systems power document extraction, visual support assistants, product search by image and text, meeting transcription, and content moderation.
